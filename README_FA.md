# کنکور سبوحا | PWA برنامه مطالعه یازدهم تجربی

ظاهر و ساختار برگرفته از «مسیر رشد» (PWA10)، با فونت وزیرمتن (Vazirmatn) که داخل پوشه `fonts` قرار دارد و آفلاین هم کار می‌کند.
برنامه پیش‌فرض از شیت «برنامه پیشنهادی مشاور» فایل اکسل ساخته شده و **مطالعه زبان انگلیسی حذف شده است** (۳۳ ساعت مطالعه در هفته).

## تب‌ها
- **خانه:** دروس، امتحان بعدی، پیشرفت امروز و هفته، بلوک‌های پیش رو، نمودار ۷ روز.
- **امروز:** تیک/درصد پیشرفت هر بلوک، یادداشت هر بلوک، یادداشت روز، کلاس‌های مدرسه و هشدار «فردا امتحان».
- **هفته:** ماتریس روز × ساعت، ساعات ثبت‌شده هر درس در برابر هدف، جبران بلوک‌های ناقص در زمان خالی فردا.
- **امتحان:** برنامه امتحانات با شمارش معکوس، افزودن/حذف امتحان، تخصیص زمان هفتگی و اصول برنامه.
- **گزارش:** جست‌وجو و فیلتر ثبت‌ها + پشتیبان/بازیابی JSON.
- **تنظیمات:** هدف ساعت هفتگی هر درس و مقایسه با برنامه، ویرایش هر فعالیت (نام، درس، چند بازه ساعت در هر روز، کپی، حذف) با هشدار تداخل، ویرایش دروس، کلاس‌های مدرسه، بازگشت به برنامه مشاور.

## انتشار روی GitHub Pages
1. در https://github.com/new یک مخزن عمومی بسازید (مثلاً `konkur-sabooha`).
2. **محتویات** همین پوشه (نه خود پوشه) را با Add file → Upload files بارگذاری کنید؛ `index.html` باید در ریشه باشد و پوشه `fonts` هم بارگذاری شود.
3. Settings → Pages → Build and deployment → Deploy from a branch → Branch: `main` و `/(root)` → Save.
4. پس از یکی دو دقیقه نشانی `https://USERNAME.github.io/konkur-sabooha/` فعال می‌شود.

## نصب روی آیفون
نشانی را در **Safari** باز کنید → دکمه Share → **Add to Home Screen**. از آن به بعد مثل یک اپ تمام‌صفحه و آفلاین اجرا می‌شود.

## نکات
- داده‌ها فقط روی همان گوشی ذخیره می‌شوند و بین دستگاه‌ها همگام نمی‌شوند؛ هفته‌ای یک بار از تب «گزارش» پشتیبان بگیرید (در آیفون منوی اشتراک باز می‌شود؛ Save to Files).
- برای به‌روزرسانی نسخه: فایل‌ها را جایگزین کنید و در `sw.js` عدد `CACHE` را یکی بالا ببرید.
